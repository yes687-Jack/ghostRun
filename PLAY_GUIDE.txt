GHOST RUN — Windows 展示版

请先完整解压 ZIP。不要在压缩包中直接运行，也不要单独复制 EXE。

Start_Game.cmd：打开开始界面，正常游玩。
Start_EffectDebug.cmd：进入效果调试，角色自动闪避，右侧调节画面和后处理。
Start_AI_Mock.cmd：需要 Python 3.10+；启动 HTTP 模拟模型，展示 AI 在三个视觉策略之间的环境调度，不消耗 API。
Start_AI_Model.cmd：需要 Python 3.10+，先在终端设置 AI_MODEL、AI_API_KEY、AI_BASE_URL，再从同一终端运行。密钥不会写入展示包；需要对应模型服务的网络权限与额度。

A/D 或左右方向键：换道 / 转弯
普通弯道在弯前约 0.25 秒内按正确方向；T 字路口从进入路口区域到真正撞墙前，都可以按 A 或 D 转弯。T 字转弯保留按键当时所在的赛道，未按键撞墙才失败。
Shift：主动减速；E：扫描屏幕内、前方 30 米内的 T 字岔口路牌，之后手动转弯可触发对应的动作 POP
跑速默认每跑 12 秒升一档，2 秒内平滑增加 0.1 倍基准速度；最多 10 档，即基准跑速的 2 倍。暂停不计时，重新开始后从 0 档计时。滑铲、转弯和换道的速度可在 GM 面板调整。红黄绿拾取物是与原尺寸一致的三色全息钻石。
空格/W/上方向键：跳跃
S/下方向键/左 Ctrl：滑铲
P：暂停；R：重新开始
碰撞障碍扣 30 点稳定度并在头顶提示；稳定度每秒下降 2%。红/黄/绿拾取物只增加对应颜色 1% 进度，不直接恢复稳定度。任一颜色满格后稳定度立即回满，战术几何轮廓从角色位置向远处扩散；三条进度条在 10 秒内归零，滤镜随之关闭。
F4：GM 跑酷参数；F10：摄影机设置；F11：效果调试；Esc：关闭调试面板或退出
GM 面板可调滑铲距离、跳跃高度、初始速度、每档增加速度、加速间隔、最高速度上限、滑铲速度加成、转弯速度和换赛道速度。数值即时生效。点击“保存并导出 Log”后，面板会显示参数文件和 Log 的实际绝对路径及完整文件名；文件分别位于本机 Saved/Config/GMSettings.ini 和 Saved/GMLogs/GMSettings_YYYYMMDD_HHMMSS_mmm.log。
Alt+Enter：切换全屏

记忆碎片分为过去、现在、未来三类。每局记忆值达到 12 时进入一次 10 秒稳定态，结束后继续跑酷，不再出现路线选择或五段自动结局。失败后出现本局身份报告，PageUp/PageDown 翻页，R 开始新一局；档案、册子与划痕跨局保留。
F12：叙事调试。PageUp/PageDown 选动作组，Tab 选过去／现在／未来，Insert 预览动作 POP，Home 模拟碎片（只改调试计数，不写存档），End 单独触发稳定态，Delete 查看报告；1/2/3 分别开关旁白、档案输出、塔奇克马通讯。关闭 F12 后恢复正常显示。

F11 面板可以调整灯光、Lumen、体积雾、丁达尔光束、雨水、曝光等。“环境设置 · 常驻镜头效果”可调默认开启的 CRT 终端传输和横向拖光；另可预览 18 种后处理。
“整体颜色重映射”可一键选青粉、琥珀、冷钢氛围，也可分别调暗部、中间调和亮部的颜色；它可与选中的后处理材质叠加。
普通展示版使用本地模拟，无需 API 密钥、Python 或 Unreal 编辑器。AI 模式使用随包附带的本地网关，仅监听 127.0.0.1；游戏退出后网关自动关闭。画面右下会显示模型选择的视觉策略、强度及来源。

需要 64 位 Windows 和支持 DirectX 12 / Shader Model 6 的显卡及较新驱动。
光线追踪、Lumen 和粒子角色对显卡要求较高，可在 F11 中降低内部渲染比例和画质参数。
首次启动可能需要较长时间。若缺少运行库，安装 Engine/Extras/Redist/en-us 下的 vc_redist.x64.exe。
